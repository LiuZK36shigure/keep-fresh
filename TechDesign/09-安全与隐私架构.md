# 09 · 安全与隐私架构

> 对个人数据类产品，**隐私是第一位**（07 §1），也是差异化卖点（"你的冰箱只有你知道"，11 §9）。
> 本章把 07 §1 的"本地优先"落实为可执行的工程规范：数据边界、最小收集、
> 订阅消息的数据权衡、合规动作、账号删除链路。
> PRD 依据：07 §1 隐私与数据安全、11 §9 隐私事故对策、01 §4.1 产品边界。

---

## 1. 数据分级与处置策略

| 数据级 | 内容 | 存储位置 | 默认行为 |
| ---- | ---- | ---- | ---- |
| L0 用户内容 | 物品明细、照片、语音文本、备注 | **仅端侧** | 不上云；照片存本地文件系统 |
| L1 必要业务数据 | 订阅提醒计划（itemId+品类名+到期日+文案键） | 端侧 + 云端 remind_plans | **仅用户授权订阅后**上报（01 §3） |
| L2 匿名统计 | 埋点事件、错误码、校准方向 | 端侧队列 + 云端 events | 匿名化后上报（07） |
| L3 产品配置 | 知识库、文案、开关 | 云端为源，端侧缓存 | 全量下发 |

**边界动作（写进代码 review 检查项）**：

- 任何 `wx.cloud.callFunction` 参数中**不得包含**物品名/照片/备注等 L0 内容（analytics 的
  品类大类枚举除外）；CI 静态检查 + 人工 review 双保险；
- 云数据库客户端直读权限默认关闭（03 §3），防止"合法功能"悄悄扩大数据面。

---

## 2. 订阅消息的隐私权衡（01 §3 / 03 §4 的设计说明）

> 这是本地优先架构的**唯一例外**，必须向用户透明：

- **为什么必须上云**：订阅消息只能由服务端（云函数）在定时任务中发送，端侧无法代发；
- **上云什么**：仅"用户点击授权的那一件物品"的最小提醒计划，不含数量、照片、备注、开封状态；
- **用户控制**：设置页"提醒授权管理"可查看/取消任一物品的订阅（取消即删云端 remind_plan）；
- **合规声明**：在《用户隐私保护指引》中如实声明收集项：openid、订阅授权记录、匿名统计；
  （07 §1.3：最小必要原则）
- **不用云端存物品明细换便利**：家庭共享（P1）才涉及共享物品上云，届时单独做成员知情同意。

## 3. 传输与存储安全

| 项 | 措施 |
| ---- | ---- |
| 传输 | 小程序网络默认 HTTPS（微信平台强制）；云开发链路平台托管 |
| 身份 | V1 无密码体系，全部基于微信 openid（07 §6）；云函数用 `cloud.getWXContext()` 取身份，**不信客户端传参** |
| 云数据库 | 安全规则最小授权 + 云函数白名单校验（03 §3） |
| 云存储 | 备份/导出文件仅本人可读；导出链接 7 天过期（03 §5） |
| 端侧 | 本地存储不加密（小程序沙箱内），但照片等敏感文件放 USER_DATA_PATH（应用私有目录）；**不落任何日志含用户内容** |
| 语音 | 识别后录音不留存（07 §1.1）；识别文本解析后不持久化原文 |

## 4. 账号与数据删除链路（07 §1.2 用户控制权）

```
设置页 → 彻底删除账号
  → 端侧：清空本地 items/photos/队列/缓存（保留 5 秒撤销提示，防误触）
  → 云端（user 云函数 deleteAccount）：
      删除 users 文档 → 删除该 openid 全部 remind_plans
      → （P1）删除 families 成员关系 → 删除备份/导出文件（云存储）
  → 确认页展示"已删除 X 条记录、Y 张照片"（透明反馈）
  → 7 天内完成（07 §1.2 承诺，实际秒级完成，台账留痕）
```

**数据导出（P1，07 §1.2）**：JSON/CSV 全量导出（含 schemaVersion，04 §6），
通过 export 云函数生成文件到云存储 → 临时链接下载。

## 5. 最小收集审计清单（每次发版前过一遍）

- [ ] 新增云函数参数不含 L0 用户内容；
- [ ] 新增埋点事件在事件白名单内，props 只有枚举/分类值；
- [ ] 隐私保护指引与"实际收集项"一致（改收集项必须先改指引再发版）；
- [ ] 无新增第三方 SDK（引入任何 SDK 前先回答：必要吗？数据流向哪？）；
- [ ] 微信后台的权限申请（麦克风/相册）与功能实际使用一致，且都有降级路径。

---

## 6. 合规要点（07 §1.3）

| 项 | 动作 |
| ---- | ---- |
| 《个人信息保护法》 | 最小必要原则；隐私指引如实声明；无账号体系（V1），不收集未成年人数据 |
| 小程序审核 | 类目选择"工具-生活服务"；隐私接口（麦克风）用途说明 |
| 免责声明 | 设置页"关于"常驻：估算仅供参考，以包装与实物为准（11 §2 对策） |
| 数据主体权利 | 导出（P1）、彻底删除（V1 提供） |

---

## 7. 隐私事故应急（11 §9 对策落地）

1. 事故面天然最小（明细不上云）；
2. 若发生云端数据异常（如 remind_plans 泄露风险）：
   - 立即关停相关云函数/收紧安全规则（5 分钟可完成）；
   - 通过公告配置（06 §1）通知用户并说明补救；
   - 复盘并更新本架构文档（活文档原则）。
