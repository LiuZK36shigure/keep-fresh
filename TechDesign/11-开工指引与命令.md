## 1. 阶段①：monorepo 骨架（约 10 分钟）

```powershell
# 进入代码目录
cd D:\keep-fresh\code

# 创建目录骨架
New-Item -ItemType Directory -Force `
  shared/src/types, shared/src/schemas, shared/src/core, `
  miniprogram, cloudfunctions, config/scripts, tools
```

### 1.1 根 package.json（覆盖写入 code/package.json）

```json
{
  "name": "keepfresh",
  "private": true,
  "scripts": {
    "typecheck": "tsc --noEmit",
    "test": "vitest run",
    "test:watch": "vitest",
    "validate:config": "node config/scripts/validate.js"
  }
}
```

### 1.2 安装工具链

```powershell
pnpm add -D typescript vitest @types/node tsx
```

### 1.3 tsconfig.json（覆盖写入 code/tsconfig.json）

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "types": ["node"],
    "noEmit": true
  },
  "include": ["shared/src"]
}
```

### 1.4 vitest.config.ts（覆盖写入 code/vitest.config.ts）

```ts
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    include: ['shared/src/**/*.test.ts'],
  },
})
```

### 1.5 冒烟文件（验证链路通）

`shared/src/types/index.ts` 写一个最小类型（完整 Item 模型等阶段②）：

```ts
/** 品类规则（完整 schema 见 TechDesign/04 §3，阶段⑤填充） */
export interface CategoryRule {
  id: string
  name: string
  model: 'date' | 'state'
}
```

`shared/src/smoke.test.ts`：

```ts
import { describe, expect, it } from 'vitest'
import type { CategoryRule } from './types'

describe('smoke', () => {
  it('类型与测试链路可用', () => {
    const rule: CategoryRule = { id: 'milk_fresh', name: '鲜牛奶', model: 'date' }
    expect(rule.model).toBe('date')
  })
})
```

### 1.6 验证（阶段①完成定义）

```powershell
pnpm typecheck   # 期望：0 错误
pnpm test        # 期望：1 个测试通过
```
