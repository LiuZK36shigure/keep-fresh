# 06 · 信息架构与核心流程

> 本章定义：页面结构（信息架构）、物品生命周期状态模型、以及 4 条关键流程。
> 线框为**低保真示意**（开发前用 Figma 出高保真稿）。

---

## 1. 信息架构（IA）

```
保鲜盒 App（小程序）
│
├── 首页（今日）
│   ├── 今日提醒汇总横幅（临期/过期 X 件）
│   ├── 临期清单（按到期日排序，前 3 条 + "查看全部"）
│   ├── 快捷记录入口（语音大按钮 / 拍照 / 手动）
│   └── 常用品快捷模板（横向滑动）
│
├── 我的物品
│   ├── 分组视图：冰箱冷藏 / 冰箱冷冻 / 储物柜 / 药箱 / 化妆台 / 其他
│   ├── 排序：到期日升序（默认）/ 购买时间 / 自定义
│   ├── 筛选：临期中 / 已过期 / 已开封 / 全部
│   ├── 搜索（名称/品类）
│   └── 物品卡片 → 物品详情
│
├── 记录（语音为主，常驻底部中央大按钮）
│   ├── 语音录入 → 确认页（品类/数量/日期/开封/位置/气候提示）
│   ├── 拍照录入（P1）
│   └── 手动表单
│
├── 统计（P1）
│   ├── 本月报告：记录数 / 用完数 / 丢弃数 / 避免浪费金额
│   ├── 连续记录天数 / 徽章墙
│   └── 浪费构成（按品类）
│
├── 家庭（P1）
│   ├── 家庭空间 / 成员管理 / 邀请
│   └── 共享物品库视图
│
└── 设置
    ├── 气候档案（城市 / 夏季 / 潮湿 / 梅雨开关）
    ├── 提醒设置（时间窗 / 免打扰 / 按类型开关）
    ├── 隐私（照片本地存储开关 / 数据导出 / 删除账号）
    ├── 知识库版本与更新日志
    └── 关于（免责声明）
```

**导航设计**：底部 Tab = 【首页】【我的物品】【＋（语音大按钮）】【统计】【我的（设置+家庭）】。
语音按钮居中放大，与整体"圆润温暖"风格一致。

## 2. 物品生命周期状态模型

```
        ┌──────────┐
        │  已记录   │◄──────────────┐
        │ (未开封)  │               │
        └────┬─────┘               │
             │ 用户标记"开封了"      │
             ▼                     │
        ┌──────────┐   延后(≤2次)   │
        │  已开封   │───────────────┘
        │ (计时中)  │
        └────┬─────┘
             │
    ┌────────┼──────────────────┐
    ▼        ▼                  ▼
┌────────┐ ┌────────┐      ┌─────────┐
│ 临期中  │ │ 已过期  │      │ 处置完成 │
│ (提醒中) │ │ (提醒)  │      │ 用完/丢弃 │
└────────┘ └────────┘      │ /转赠    │
                           └─────────┘
```

状态说明：

| 状态 | 定义 | 触发动作 |
| ---- | ---- | ---- |
| 已记录（未开封） | 记录保存，未开封 | 无提醒（长保品可在 V1.1 增加"已存 X 天"弱提醒） |
| 已开封 | 用户标记开封 | 开始 T1 倒计时，按 05 §1.2 生成开封提醒 |
| 临期中 | 距到期 ≤ 提前提醒天数 | 生成临期提醒（05 §1.2 分档） |
| 已过期 | 超过推算到期日 | 生成过期提醒；列表置顶（温和样式） |
| 处置完成 | 用完/丢弃/转赠 | 移入历史，计入统计；支持 5 秒内撤销 |

## 3. 关键流程

### 3.1 流程一：语音记录（黄金时刻，目标 ≤ 10 秒）

```
[首页/任意页] 点语音大按钮
      │
      ▼
[语音页] 动画提示"说吧～"（显示示例：'牛奶，今天买的'）
      │ 用户说话
      ▼
[识别中] 转菊花 ≤3 秒（无网则直接跳手动表单）
      │
      ▼
[确认页] 展示解析结果：
   品类：鲜牛奶  ✔
   数量：1 箱（可改）
   购买日：今天（可改）
   开封：未开封（可改）
   存储：冷藏（可改）
   ──────────────────────
   预计到期：7 天后（高温潮湿季 → 6 天）
   [估算依据：基线7天×气候0.8] ⓘ
   [保存] [重说]
      │
      ▼
[保存成功] 动画反馈 + 可选："到期前提醒你吗？"（订阅授权）
```

**设计要点**：
- 确认页是"纠错安全网"：识别错了用户一眼能改，**信任感来源于可纠正**；
- 保存成功页同时是**提醒订阅的黄金时机**（见 05 §2）；
- 语音识别规则（F-01 解析规则）在 03 章定义。

### 3.2 流程二：拍照记录（P1）

```
记录页 → 拍照按钮 → 拍摄/相册选图
   → 快速裁剪（可选）→ 附加到"待确认物品"表单
   → 与语音/手动一样进入确认页（照片缩略图随卡片展示）
   → 保存
```

### 3.3 流程三：提醒 → 处置

```
推送/横幅：'牛奶还有 2 天到期 [已用完][已丢弃][转赠][延后3天]'
      │
      ├─ 已用完 → 物品完成 + 金额统计 + 撤销机会(5s)
      ├─ 已丢弃 → 同上（计入浪费统计）
      ├─ 转赠   → 标记转赠（P1 可分享给家人）
      └─ 延后3天 → 重排提醒（上限2次）
```

### 3.4 流程四：新用户引导（第一次打开，90 秒内跑通闭环）

```
欢迎页（一句话价值 + 插画）
   → 引导设置气候档案（城市 + 2 个问题：夏天闷热吗？家里潮湿吗？）
   → 示例物品引导：'试着对它说：牛奶，今天买的'（可直接点示例语音）
   → 记录成功后引导开启提醒授权
   → 进入首页（已有 1 件示例物品在清单里）
```

**设计要点**：新用户必须在第一次会话内**完成一次"记录"**，否则大概率流失；
示例物品引导让用户 30 秒内体验完整价值。
