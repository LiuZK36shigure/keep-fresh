# 07 · 非功能需求（NFR）

> 非功能需求决定用户"用起来舒不舒服、敢不敢用"。对个人数据类产品，**隐私是第一位**。

---

## 1. 隐私与数据安全（最高优先级）

### 1.1 设计原则：本地优先（Local-First）

- 物品记录、照片、语音内容**默认只存储在用户设备本地**（小程序：本地缓存 + 用户云盘可选备份）；
- **照片不上传服务器**（除非用户明确开启云备份，默认关闭）；
- 语音识别：优先使用**端侧/系统级识别**；WechatSI 等云端识别时，录音**不留存**，仅回传识别文本；
  ⚠️ **隐私声明（2026-08 修订）**：WechatSI 为微信云端识别，语音内容将发送至微信服务器处理——
  该事实必须在《用户隐私保护指引》中如实声明（见 TechDesign 09 §3）；
- 服务器（若有）只保存匿名化统计（埋点事件），不保存物品明细。

### 1.2 用户控制权

| 能力 | 要求 |
| ---- | ---- |
| 数据导出 | 一键导出全部数据（JSON/CSV），V1.1 提供 |
| 彻底删除 | 删除账号 = 删除全部云端与本地关联数据，7 天内完成 |
| 隐私开关 | 设置页明示：云备份（默认关）、个性化推荐（无）、数据共享（无） |
| 未成年人 | 无账号体系（V1），不存在儿童数据收集问题；家庭共享需成员确认 |

### 1.3 合规

- 遵循《个人信息保护法》最小必要原则；小程序需在《用户隐私保护指引》中如实声明收集项；
- 免责声明（见 11-风险与对策 §2）：保质期推算为估算，不构成食品安全建议。

---

## 2. 性能要求

| 场景 | 指标 |
| ---- | ---- |
| 冷启动（小程序首屏可交互） | ≤ 2 秒（弱网 ≤ 3 秒） |
| 语音识别 → 确认页展示 | ≤ 3 秒 |
| 物品列表渲染（500 条） | ≤ 1 秒 |
| 提醒计算（每日定时任务） | 每批 ≤ 1 分钟完成（云函数分桶链式分批，2026-08 修订，见 TechDesign 03 §4） |
| 知识库更新拉取 | 后台静默，不阻塞任何操作 |

## 3. 可用性与离线

- **离线可用**：无网络时仍可记录（语音降级为手动）、查看本地物品、展示离线版知识库；联网后自动同步/更新；
- 网络恢复后提醒补发策略：错过的提醒在下次打开 App 时以横幅汇总出现，不补推骚扰；
- 弱网（3G）下所有核心操作可用。

## 4. 兼容性（取决于平台决策，见 09 §3）

| 平台 | 要求 |
| ---- | ---- |
| 微信小程序（V1 首选） | 基础库 ≥ 2.30；iOS/Android 双端一致；适配全面屏与平板 |
| 原生 App（V2 候选） | iOS 15+ / Android 10+；支持系统推送与灵动岛/通知栏样式 |

## 5. 可维护性与配置化（一人公司的生命线）

| 项 | 要求 |
| ---- | ---- |
| 品类知识库 | 远程 JSON 配置（`shelf_rules.json`），带版本号，**改规则不发版** |
| 文案库 | 远程 JSON 配置（`copywriting.json`），同上 |
| 功能开关 | 远程开关（Feature Flag），可随时关闭有问题的功能 |
| 错误上报 | 极简错误日志（页面/操作/错误码），不上传用户内容 |
| 后端依赖 | 尽量 Serverless（云函数 + 云数据库），无服务器运维负担 |

## 6. 安全

- 埋点与同步接口使用 HTTPS；不做用户密码体系（V1 依赖微信身份）；
- 上传内容（若有）脱敏：不传照片、不传物品名之外的明细。

## 7. 无障碍（P1）

- 字号适配系统"大字体"设置；语音按钮有明确文字标签；
- 颜色对比度满足 WCAG AA；提醒不依赖单一红色表达（色盲友好）。

## 8. 国际化（远期，不做）

- V1 仅简体中文；知识库与文案结构预留 i18n 键位，避免后期重构。
