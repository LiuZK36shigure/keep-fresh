# 保鲜盒 KeepFresh

> 一款生活化的个人物品保质期管家：用语音 3 秒记录你买的东西，结合本地气候与物品特性推算"真实可用期限"，在合适的时间温柔提醒你。

## 为什么做这个

- **记不住**：冰箱深处的酸奶过期一周才发现，贵价护肤品开封后放到过期
- **算不准**：开封前后、夏冬气候不同，"保质期" ≠ "能吃的期限"
- **提醒太粗暴**：要么没有提醒，要么到期才弹一个冷冰冰的"已过期"

一句话：帮你把买的东西**用完**，而不是堆到过期。

## 功能特性

- 🎤 **语音记录**：说一句"牛奶，今天买的"，自动识别品类、数量、日期
- 🧮 **保质期推算**：品类基线 × 开封状态 × 气候因子，三层规则引擎，可解释、可校准
- 🍓 **生鲜果蔬支持**：状态驱动模型，给"建议窗口"和检查提醒，不承诺做不到的精确
- 🔔 **温柔提醒**：临期 / 过期 / 开封计时 / 检查四类提醒，生活化文案，自动合并防打扰
- ✅ **处置闭环**：用完、丢弃、转赠，一键标记，还能看到"本月避免浪费 X 元"
- 📷 **拍照归档**：记录产品状态，为多模态能力铺路（规划中）
- 🔒 **本地优先**：数据默认只存本地，隐私是产品的信任资产

## 技术栈

- **前端**：微信小程序
- **后端**：微信云开发（Serverless，零运维）
- **规则引擎**：可远程更新的 JSON 知识库（`shelf_rules.json` + `copywriting.json`）
- **AI 定位**：LLM 仅用于语音/文本的"听懂"兜底解析（规则优先），**从不生成期限数值**，保证推算可解释、可追责
